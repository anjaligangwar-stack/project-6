 BMI Calculator - VEDA Internship Project

A simple and responsive BMI (Body Mass Index) Calculator built with HTML, CSS, and JavaScript.

Internship: VEDA - Frontend Development
Project Day: Day 6
Project Name: BMI Calculator

✨ Features (Day 6 Task)
- Calculate BMI from Height (cm) and Weight (kg)
- Live BMI Preview on input (`input` event)
- Shows Health Status: Underweight, Normal, Overweight, Obesity
- Input validation & Alert for invalid values
- Clean and responsive Card UI
- Calculate Button + Result Box
 
 Tech Stack
- HTML5 - Structure
- CSS3 - Styling & Responsive Card Layout
- JavaScript - Logic


Health Status Logic:
- BMI < 18.5 = Underweight
- BMI 18.5 - 24.9 = Normal weight
- BMI 25 - 29.9 = Overweight
- BMI >= 30 = Obesity

 What I Learned on Day 6

- Difference between click and input event in JS
- Importance of `<script src="index.js"></script> at end of body
- Use of parseFloat() and validation
